# Curated storefront fonts

These self-hosted Latin webfonts are distributed under the SIL Open Font License 1.1:

- Archivo Narrow
- Atkinson Hyperlegible
- Fraunces
- IBM Plex Mono
- Inter
- JetBrains Mono
- Roboto Slab
- Source Serif 4
- Space Grotesk

The files were obtained from the corresponding `@fontsource` or `@fontsource-variable` packages. Fontsource preserves each upstream font's OFL license and metadata. Runtime storefronts load only these local files; they do not contact a font CDN.

See `OFL-1.1.txt` in this directory for the license terms.
